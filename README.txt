NUHRA — PRODUCTION HOSTINGER PACKAGE

UPLOAD
1. Extract this ZIP.
2. Hostinger hPanel > Websites > Manage > Files > File Manager.
3. Open public_html.
4. Upload ALL files and folders while preserving structure.
5. Ensure index.html is directly inside public_html.

CONTACT FORM
- contact.php sends enquiries to connect@nuhra.in.
- Hostinger must have PHP mail enabled and the domain mail settings configured.
- Recommended production improvement: configure SMTP authentication through a transactional email provider if Hostinger mail() is restricted.

ASSETS
- assets/images contains the uploaded NUHRA images used throughout the site.
- assets/video/showreel.mp4 contains the uploaded showreel.

BEFORE LAUNCH
- Test the form on the live Hostinger domain.
- Add real social links and legal pages if required.
- Optimize video further if load speed is an issue.
